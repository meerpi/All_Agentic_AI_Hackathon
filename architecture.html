Core Architectural Innovations

Topological Sort & Cycle Guard

Prevents deadlocks using Kahn's algorithm, guaranteeing that steps execute in strict dependency order while maximizing parallel throughput.

Dynamic Cross-Step Referencing

Allows downstream tasks to consume structured outputs from upstream steps using $step_1.results[0].video_id or $step_2.doc_url seamlessly.
